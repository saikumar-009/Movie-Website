# 🎬 Movie Website

A responsive movie browsing application built with React.js.

## 🚀 Live Demo

https://saikumar-009.github.io/Movie-Website/

## ✨ Features

- Search movies
- View movie information
- Responsive design
- API Integration
- Modern UI
- Dark-Mode

## 🛠️ Technologies Used

- React.js
- JavaScript
- CSS3
- TMDB API
